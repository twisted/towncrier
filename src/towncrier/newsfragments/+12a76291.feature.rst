Adding a type to configuration with just ``default_types = true`` will insert the default types rather than needing to duplicate them.

For example, to add a new ``description`` type first, but keep all of the other default types::

   [[tool.towncrier.type]]
   name = ""
   directory = "description"
   all_bullets = false
   check = false

   [[tool.towncrier.type]]
   default_types = true
